# SoulCraft roadmap

Updated 2026-11-02. Implemented prototype behavior and future gates are separate.

## Implemented

- Earlier standalone Genesis and v0.2 Elemental Renderer demos in `prototypes/`.
- Creator v0.3–v0.3.3 in `creator/`: daily local goal/XP, persistence, naming, cosmetic craft, JSON backup/validated restore and local PNG sharing.
- The root Pages entrypoint remains the older v0.2 demo; Creator is a separate app.

## Next gate

Implement a distinct three-form evolution for one origin, linked to existing 0/40/80 XP milestones, preserving saved names/goals/craft and share privacy. Verify actual UI selection and asset loading as well as model boundaries before publishing.

## Subsequent proposals

1. Mobile review of recognition and layout; a small voluntary Creator usability trial.
2. Expand evolution assets only after first-origin feedback.
3. Limited Companion check-in and Spark card previews.
4. Cross-device persistence if justified by usage, with explicit privacy and hosting choices.

Later only: full 3-of-5 fusion in Creator, humanoid animation, Expo app, GFLO/OctoPush adapters and opt-in shared Essence features. No promised dates or completed backend/AI claims.
